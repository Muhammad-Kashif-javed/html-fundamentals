# HTML Fundamentals

A collection of HTML practice exercises and projects covering the fundamental concepts of web development. This repository serves as a learning resource and showcases hands-on experience with HTML5.

## 📚 Topics Covered

- HTML Document Structure
- Headings and Paragraphs
- Text Formatting Tags
- Links and Images
- Lists
- Tables
- Forms
- Semantic HTML
- Multimedia Elements
- HTML Best Practices

## 🎯 Objectives

- Build a strong foundation in HTML5
- Learn how to structure web pages effectively
- Understand semantic and accessible markup
- Develop clean and maintainable code
- Prepare for advanced frontend technologies such as CSS and JavaScript

## 🛠️ Technologies Used

- HTML5
- Visual Studio Code
- Live Server
